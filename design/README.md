# Adaptive Knife Holder

This folder contains the design and prototyping files for an **assistive knife holder** developed during my internship with **Humanos 3D** in Medellín, Colombia.

The device was designed to support a user who required additional stability and control while handling a kitchen knife. The project involved translating an individual user's needs into a practical 3D-printable solution, then refining the design through multiple components and iterations.

## Design Files

The folder includes several components developed for the final device:

- **Knife Holder** — primary component used to support and stabilize the knife
- **Knife Cover** — protective enclosure incorporated into the final design
- **Protection Piece** — additional component designed to improve safety
- **Velcro Component** — attachment feature used to help secure the device
- **Right-Hand Knife Holder Cover** — geometry adapted for right-hand use

The STL files are provided as fabrication-ready models for 3D printing.

## Human-Centered Design Process

The design was developed around the needs of a specific user rather than around a predetermined mechanical concept.

The process involved:

1. Understanding the user's functional needs and limitations
2. Translating those needs into mechanical design requirements
3. Developing and modifying CAD geometry
4. Producing 3D-printable prototypes
5. Refining the device based on fit, usability, safety, and user interaction

This iterative process reinforced my interest in **human-centered engineering**, particularly the role that mechanical design and rapid prototyping can play in creating individualized assistive technology.
